002 : NAVSEA Submarine Lifecycle Analysis

← Back to projects

Note

This project was completed during my internship at NSWC Corona (Fall 2025). Data and materials have been modified or omitted to protect sensitive information.

Problem

Naval lifecycle data can be difficult to analyze when records contain inconsistent formatting, missing values, mixed date formats, and duplicate entries. These issues make it harder to identify maintenance timelines, operational trends, and decision-relevant patterns.

Solution

I built Python data-cleaning workflows and Tableau dashboards to transform raw submarine lifecycle data into structured, analyzable outputs. The project focused on improving data reliability and making lifecycle patterns easier to interpret visually.

My Role

I cleaned and standardized lifecycle data, corrected invalid date sequences, mapped hull numbers to submarine names, removed duplicate records, and built Tableau dashboards to communicate maintenance and operational trends.

Technical Implementation

  • Used Python, Pandas, and NumPy to clean and standardize lifecycle datasets
  • Handled inconsistent date formats and corrected records where start dates occurred after end dates
  • Standardized categorical fields such as location, ship class, and period type
  • Mapped hull numbers to submarine names using an external lookup table
  • Removed duplicate records and prepared cleaned data for Tableau visualization

Analytics & Visualization

  • Built Tableau dashboards to visualize submarine lifecycle and maintenance activity
  • Created timeline/Gantt-style views to track operational periods over time
  • Used line and map-based visualizations to explore trends by duration, location, and activity type

Impact

  • Improved data quality by resolving inconsistencies, missing values, and duplicate records
  • Made lifecycle and maintenance patterns easier to explore through interactive dashboards
  • Turned raw operational data into clearer decision-support visuals for technical stakeholders

Tech Stack

  • Python
  • Pandas
  • NumPy
  • Tableau
  • Excel
