001 : Query-to-Insight Analytics Engine

🏆 2nd Place Winner — Microsoft Innovation Challenge Hackathon (March 2026)

← Back to projects

Problem

Traditional analytics workflows require writing SQL queries manually, which creates a barrier for non-technical users and slows down data-driven decision making. Analysts often spend significant time translating business questions into queries before generating insights.

Solution

My team and I built a full-stack analytics application that converts natural language questions into secure SQL queries and structured insights. The system allows users to interact with data using plain English, removing the need for manual SQL writing.

Technical Implementation

  • Developed a FastAPI backend to process user queries, handle API requests, and manage end-to-end query execution
  • Integrated Azure OpenAI to translate natural language into SQL queries
  • Connected to Azure SQL database for structured data retrieval
  • Built a React frontend to capture user input and display results
  • Implemented validation safeguards to prevent unsafe or invalid queries
  • Designed role-based access controls to ensure secure data usage
  • Designed an end-to-end pipeline from user input → AI processing → SQL execution → structured output

Impact

  • Reduced time required to generate insights from manual querying to near real-time responses
  • Enabled non-technical users to interact with structured datasets
  • Improved efficiency in analytics workflows through automation
  • Project awarded 2nd place in the Microsoft March 2026 Innovation Challenge

Tech Stack

  • Python (FastAPI)
  • React (Frontend)
  • Azure OpenAI
  • Azure SQL
  • Redis (Caching)
