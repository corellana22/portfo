005 : FIFA Player Valuation

← Back to projects

Project Overview

Built a sports analytics project using FIFA player data to analyze what factors influence player market value. The project focused on modeling valuation using player attributes, performance ratings, age, potential, and position-based features.

Approach

  • Cleaned and explored an 18,000-player FIFA dataset
  • Analyzed relationships between player attributes, overall rating, potential, age, and market value
  • Used regression modeling to estimate player value
  • Compared feature importance to identify the strongest drivers of valuation
  • Visualized trends among high-value players and young players with high potential

Key Takeaway

Player valuation was strongly influenced by overall rating, potential, age, and position-specific performance attributes. The project showed how sports data can be used to support scouting, player comparison, and valuation analysis.

Tech Stack

  • Python
  • Pandas
  • Regression modeling
  • Feature importance analysis
  • Data visualization
